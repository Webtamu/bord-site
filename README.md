# bord-site

The BORD marketing site, deployed to GitHub Pages on every push to main.
Public by necessity (free Pages) and by nature (it's the marketing site).
Sisters: `Webtamu/bord` (product, private) · `Webtamu/bord-hq` (business
& marketing docs, private — brand/voice rules live there in
marketing/BRAND.md).

## The scrapbook system (2026-09-13)

The site mirrors the app's shipping "Milk Tea & Blush" album
(`bord/ios/Bord/Theme.swift` `mt*` tokens, read through
`Prototypes/BordNew/BNTheme.swift`): kraft cover, paper interiors, walnut
ink, one violet accent, and colour only in the hand layer — washi, page
tabs, sticker chips, stamps, stickers.

- `css/tokens.css` — the palette and type roles, one value per app token.
- `css/base.css` — the materials: paper, washi, chip, page tab, stamp, JOIN
  slot, pushpin, seat pips, the kiss-cut sticker container, Bord's cut.
- `img/stickers.svg` — the app's game and object stickers as an SVG sprite,
  generated by `tools/stickers.py` from the Swift geometry
  (`BNGameStickers.swift`). The sprite is inlined at the top of `index.html`;
  regenerate with `python3 tools/stickers.py` and paste it back in.
- `img/fiber.svg`, `img/cardstock.svg` — the kraft and paper grain tiles,
  the app's `BNFiber` / `BNCardstock` LCG, from `tools/grain.py`.
- `img/bord-face.svg` — the mascot's official export
  (`bord-assets/mobile/static/bord-face.svg`) with the body retinted to the
  accent. Bord is never redrawn.
- `img/screens/*.webp` — real simulator screenshots (iPhone 17 Pro, status
  bar cropped, 720px wide). Re-shoot from the bord repo with the
  `BORD_NEW_*` launch hooks and `BORD_DEV_LOGIN=hou:boba`.

Bump the `?v=` on the stylesheet and script URLs in `index.html` whenever
`css/` or `js/` change.
